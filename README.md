# Basic Network Sniffer

A basic Python-based network sniffer developed using **Scapy** to capture and analyze live network traffic.

This project demonstrates the fundamentals of packet capture, network protocols, IP addressing, ports, packet structure, and payload analysis.

---

## 📌 Project Overview

A network sniffer is a tool that captures network packets traveling through a network interface and displays useful information about those packets.

This project was developed as **Task 1: Basic Network Sniffer**.

The main purpose of the project is to understand:

- How network packets travel between devices
- How IP addresses identify source and destination devices
- How network protocols work
- How TCP, UDP, and ICMP packets can be identified
- How ports are used for network communication
- How packet payloads can be inspected
- How encrypted traffic differs from readable application data

---

## 🎯 Objectives

The objectives of this project are:

1. Capture live network traffic.
2. Analyze captured packets.
3. Identify source and destination IP addresses.
4. Identify network protocols.
5. Display TCP and UDP port information.
6. Inspect packet payloads.
7. Display packet sizes.
8. Understand the basic structure of network packets.
9. Learn how data flows through a network.
10. Gain practical experience with Python and Scapy.

---

## ✨ Features

The network sniffer provides the following features:

- ✅ Live packet capture
- ✅ Source IP address detection
- ✅ Destination IP address detection
- ✅ TCP protocol detection
- ✅ UDP protocol detection
- ✅ ICMP protocol detection
- ✅ Source port detection
- ✅ Destination port detection
- ✅ Payload detection
- ✅ Payload size calculation
- ✅ Hexadecimal payload preview
- ✅ Packet length calculation
- ✅ Continuous packet monitoring
- ✅ Simple command-line interface
